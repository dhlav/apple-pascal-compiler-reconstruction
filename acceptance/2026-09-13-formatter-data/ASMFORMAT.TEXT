;---------------------------------------------------
; ASMFORMAT -- the Disk II formatter: blocks 0-2 of
; APPLE3:FORMATTER.DATA. FORMATTER.CODE reads those
; three blocks to 03D00 and FORMDISK calls 03D00 with
; slot and drive in A (Apple II Technical Note Pascal
; #12, which calls this file ASMFORMAT.TEXT, gives
; its origin and its length, 1082 bytes, and ships no
; source on the 1.3 disks).
;
; Reconstructed from FORMATTER.DATA (finding 275).
; MAKEFMT copies this codefile's blocks 1-3 into the
; data file whole, so what has to match is not just
; the 1082 bytes of code but the assembler's segment
; dictionary after them and the stale end of its
; block buffer, which repeats block 1's bytes 024A-
; 03FF. Those stale bytes are the evidence for the
; .EQUs below: the delay entry 0410E and the storage
; from 0411F appear resolved there, so Apple's source
; defined them before the code that uses them. As
; forward labels they come out 0000.
;
; What is ours: every label (L<address>) and comment.
;---------------------------------------------------
