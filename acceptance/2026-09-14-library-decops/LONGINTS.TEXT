;---------------------------------------------------
; LONGINTIO's fourth procedure: the long-integer
; engine, SYSTEM.LIBRARY segment 30.
;
; The unit's other three procedures are Pascal and
; are in src/pascal/units/1.3/LONGINTIO.text. This
; one is 1706 bytes of 6502 and is the whole of Apple
; Pascal's long-integer arithmetic: every CXP 30,4 in
; the library lands here, including the two that
; LONGINTIO's own FREADDEC makes (finding 96a).
;
; Reconstructed from the 1.3 binary. Assemble with
; Apple's own SYSTEM.ASSMBLER: it generates the
; relocation tables (finding 44), and those are part
; of what has to match. It comes out byte for byte --
; 1852 bytes with the tables, 62 procedure-relative
; and 5 Interpreter-relative relocations.
;
; How it is entered. The caller pushes an operation
; number, and the first thing the procedure does is
; index OPS with it and jump indirect. The eleven
; words of OPS are the eleven operations; they are
; .WORDs of labels, which is what puts them in the
; procedure-relative relocation table, and writing
; them as addresses would leave the table eleven
; entries short and the jumps would go into page
; zero.
;
; RETURN is the common exit: it steps the saved
; return address on by one before returning through
; it, so the byte after the call site is skipped.
;
; DECLEN reaches into SYSCOM through .INTERP+4 and
; takes one off a word at offset $3C. The three
; entries after it are the error exits -- they load
; A with 5, 13 and 6 and jump through .INTERP+0, the
; Interpreter's error poster, which is the documented
; way for assembly code to raise a runtime error
; (1.3 manual IV-10).
;
; DECOPS is Apple's name: the compiler calls it that
; in its GENNR(30,4) comments, and Apple's LONGINTIO
; source declares PROCEDURE DECOPS; EXTERNAL; in text
; left in SYSTEM.LIBRARY's slack (finding 290).
;
; What is ours: every other label name and every
; comment.
; Labels written L<nnnn> are the label's offset from
; the start of the procedure and are placeholders --
; nothing about them is recovered, and naming the
; eleven operations would take reading the whole
; engine, which has not been done. The bytes are
; settled; the reading of them is not.
;
; Zero page: $76 up. The engine works on the 6502
; stack page directly, which is why $0100 turns up
; indexed throughout.
;---------------------------------------------------
