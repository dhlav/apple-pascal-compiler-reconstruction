{ SYSTEM.PASCAL -- the Apple Pascal operating system: command menu, file
  I/O primitives, error printing, initialization, and program loading.
  Codefile target is **128K.PASCAL** specifically (APPLE3:) -- the only
  build this project reads, cites, or tests against; the 64K
  `SYSTEM.PASCAL` build is out of scope entirely, by direct instruction
  (`analysis/diskset-inventory.txt` has 128K.PASCAL's own 7-segment
  layout).

  First session: the skeleton only. `PROGRAM PASCALSYSTEM` matches
  UCSD II.0's own program name exactly (`reference_source/ucsd_ii0/
  GLOBALS.TEXT`) and the shape SETUP.text's own header comment already
  worked out for a `(*$U-*)` host program wrapping `SEGMENT PROCEDURE`s
  one level in. `CONST`/`TYPE` and the VAR section below are ported
  from `GLOBALS.TEXT` (legitimate for names per the project's own
  sources-of-truth order -- UCSD source for names, re-derive structure
  from the binary) as a *starting point*, not yet verified against
  Apple's own frame sizes; `PASCALSY` (segment 0, the real 451-word
  main loop, `analysis/lifted/128K.PASCAL-1.3-128K.pas.txt`) is left a
  trivial outer body for now, deliberately deferred -- it is the single
  biggest procedure in the entire disk set and depends on getting these
  globals right first.

  **`WRITE`/`WRITELN` do not work here -- call `FWRITESTRING`/
  `FWRITELN`/etc. directly.** UCSD's own source does exactly that
  (`SYSSEGS.A.TEXT`'s `FWRITELN(SYSTERM^)`, not `WRITELN(SYSTERM^)`),
  and it turns out to be load-bearing, not stylistic: `WRITE`/`WRITELN`
  compile to these same routines as compiler sugar, but Apple's own
  compiler only accepts a *plain variable identifier* as that sugar's
  file argument -- `WRITELN(SYSTERM^)` (a pointer dereference, not an
  identifier) hits error 125 on Apple's real compiler even though the
  host compiler (`ucsdpsys_compile`) accepts it, one more case of the
  host tool being more permissive than Apple's (confirmed both ways
  directly: `WRITELN(SYSTERM^)` fails, `WRITELN(DIRECTF)` on a plain
  `TEXT` variable of the same type succeeds). Calling `FWRITELN`
  directly sidesteps the restriction entirely -- it is an ordinary
  procedure call, not compiler sugar, and ordinary `VAR` parameters
  accept any suitable expression, dereferences included. This is also
  why `FIB`, not `TEXT`, is `FWRITELN`'s own real parameter type
  (`GLOBALS.TEXT`'s own forward declaration, `PROCEDURE
  FWRITELN(VAR F: FIB); FORWARD;`) -- confirmed against the raw p-code
  too: `USERPROG.1` pushes `LOD 1,56` (a plain value load, not a
  dereference-then-load) straight into `CXP 0,22` (`OS.22`, i.e.
  segment-0 procedure 22 -- `FWRITELN`), meaning the real global at
  that offset is itself the pointer, loaded and passed as-is.

  That single fact reshaped this file: `GLOBALS.TEXT`'s own "SYSTEM
  PROCEDURE FORWARD DECLARATIONS" section (27 "fixed", addressed
  directly by object code, then 14 "non-fixed") is not a documentation
  aid, it is 41 of segment 0's own procedure declarations, and segment
  0's own body (`PASCALSY.1`, deferred) makes 42 -- exactly finding
  51a's own already-verified count for how far Apple's segment-0
  numbering agrees with UCSD's declared order. Declaring all 41 here,
  in this same order, before any `SEGMENT PROCEDURE`, lands their
  procedure *numbers* right even though every body but the two below
  is still a stub: `FINIT` (2nd declared) already matches an
  independently-recovered comment from earlier compiler work, `OS.3
  FINIT` -- procedure 3, one more than its declaration position because
  the enclosing block's own body always claims number 1.

  `USERPROGRAM` (segment 1, `USERPROG` on disk) is the one real body
  this session: UCSD's own `SYSSEGS.A.TEXT` gives it verbatim (once
  written as direct `FWRITELN`/`FWRITESTRING` calls, per above), and
  Apple's binary (`args 2 words`) matches UCSD's own 2-parameter
  declaration exactly -- unlike segment 0's own procedures 43 onward
  (finding 51c), this one is a straight, unmodified port. The other
  five segments are stubs: `PRINTERROR(XEQERR,IORSLT: INTEGER)`,
  `INITIALIZE`, and `GETCMD(LASTST: CMDSTATE): CMDSTATE` all match
  Apple's own real `args` word counts exactly against UCSD's declared
  signatures (`params=2/1/1` respectively, `analysis/lifted/
  128K.PASCAL-1.3-128K.pas.txt`), so those signatures are trusted;
  `FIOPRIMS` (`args 0 words`, real) and `FILEPROC` (`args 6 words`,
  real) have no UCSD precedent at all -- Apple-specific segments, most
  likely 128K-only code the 64K system keeps inline in segment 0.
  `FILEPROC`'s own six words dispatch on the first (`OP`) to one of
  several internal arms, mapped directly from the real binary's own
  `FILEPROC` segment (finding 156) -- `VAR F: FIB`, `VAR ARGSTR:
  STRING`, `ARGBOOL: BOOLEAN`, `ARGPTR: FIBP`, `ARGINT: INTEGER`. }

PROGRAM PASCALSYSTEM;

  CONST
    MMAXINT  = 32767;  { maximum INTEGER value }
    MAXUNIT  = 20;      { maximum physical unit # for UREAD -- UCSD
                          II.0's own GLOBALS.TEXT says 12 (1.1's own
                          value), but Neil Parker's own documented
                          DISKNUM table (evidence/reference/
                          "Undocumented Secrets of Apple Pascal.html")
                          says the OS's own internal table is "12
                          (Apple Pascal 1.1) or 20 (Apple Pascal 1.2
                          and 1.3)" -- 1.3 real, not UCSD generic }
    MAXDIR   = 77;      { max number of entries in a directory }
    VIDLENG  = 7;       { number of chars in a volume ID }
    TIDLENG  = 15;      { number of chars in a title ID }
    MAX_SEG  = 63;      { max code segment number -- 31 for the 64K
                          system, 63 for the 128K system (Neil Parker,
                          "Undocumented Secrets of Apple Pascal");
                          this build targets 128K.PASCAL }
    FBLKSIZE = 512;     { standard disk block length }
    DIRBLK   = 2;       { disk addr of the directory }
    AGELIMIT = 300;     { max age for GDIRP, in ticks }
    EOL      = 13;      { end-of-line -- ASCII CR }
    DLE      = 16;      { blank-compression code }
    NAME_LEN = 23;      { CONCAT(VIDLENG, ':', TIDLENG) }
    FILL_LEN = 11;      { max # of nulls in FILLER }

  TYPE
    IORSLTWD = (INOERROR, IBADBLOCK, IBADUNIT, IBADMODE, ITIMEOUT,
                ILOSTUNIT, ILOSTFILE, IBADTITLE, INOROOM, INOUNIT,
                INOFILE, IDUPFILE, INOTCLOSED, INOTOPEN, IBADFORMAT,
                ISTRGOVFL);

    { command states -- see GETCMD }
    CMDSTATE = (HALTINIT, DEBUGCALL,
                UPROGNOU, UPROGUOK, SYSPROG,
                COMPONLY, COMPANDGO, COMPDEBUG,
                LINKANDGO, LINKDEBUG);

    { code files used in GETCMD }
    SYSFILE = (ASSMBLER, COMPILER, EDITOR, FILER, LINKER);

    { archival info -- the date }
    DATEREC = PACKED RECORD
                MONTH: 0..12;  { 0 implies date not meaningful }
                DAY: 0..31;
                YEAR: 0..100   { 100 is temp-disk flag }
              END;

    { volume tables }
    UNITNUM = 0..MAXUNIT;
    VID = STRING[VIDLENG];

    { disk directories }
    DIRRANGE = 0..MAXDIR;
    TID = STRING[TIDLENG];
    FULL_ID = STRING[NAME_LEN];

    FILE_TABLE = ARRAY [SYSFILE] OF FULL_ID;

    FILEKIND = (UNTYPEDFILE, XDSKFILE, CODEFILE, TEXTFILE,
                INFOFILE, DATAFILE, GRAFFILE, FOTOFILE, SECUREDIR);

    DIRENTRY = PACKED RECORD
                 DFIRSTBLK: INTEGER;  { first physical disk addr }
                 DLASTBLK: INTEGER;   { points at block following }
                 CASE DFKIND: FILEKIND OF
                   SECUREDIR,
                   UNTYPEDFILE:       { only in DIR[0] -- volume info }
                     (FILLER1: 0..2048;
                      DVID: VID;
                      DEOVBLK: INTEGER;
                      DNUMFILES: DIRRANGE;
                      DLOADTIME: INTEGER;
                      DLASTBOOT: DATEREC);
                   XDSKFILE, CODEFILE, TEXTFILE, INFOFILE,
                   DATAFILE, GRAFFILE, FOTOFILE:
                     (FILLER2: 0..1024;
                      STATUS: BOOLEAN;   { for FILER wildcards }
                      DTID: TID;
                      DLASTBYTE: 1..FBLKSIZE;
                      DACCESS: DATEREC)
               END;

    DIRP = ^DIRECTORY;
    DIRECTORY = ARRAY [DIRRANGE] OF DIRENTRY;

    { file information }
    CLOSETYPE = (CNORMAL, CLOCK, CPURGE, CCRUNCH);
    WINDOWP = ^WINDOW;
    WINDOW = PACKED ARRAY [0..0] OF CHAR;


    FIBP = ^FIB;

    FIB = RECORD
            FWINDOW: WINDOWP;  { user window, F^, used by GET/PUT }
            FEOF, FEOLN: BOOLEAN;
            FSTATE: (FJANDW, FNEEDCHAR, FGOTCHAR);
            FRECSIZE: INTEGER; { bytes; 0=>block file, 1=>char file }
            CASE FISOPEN: BOOLEAN OF
              TRUE: (FISBLKD: BOOLEAN;   { file is on a block device }
                     FUNIT: UNITNUM;
                     FVID: VID;
                     FREPTCNT,          { # times F^ valid w/o GET }
                     FNXTBLK,           { next rel block to IO }
                     FMAXBLK: INTEGER;  { max rel block accessed }
                     FMODIFIED: BOOLEAN;
                     FHEADER: DIRENTRY; { copy of disk dir entry }
                     CASE FSOFTBUF: BOOLEAN OF
                       TRUE: (FNXTBYTE, FMAXBYTE: INTEGER;
                              FBUFCHNGD: BOOLEAN;
                              FBUFFER: PACKED ARRAY [0..FBLKSIZE] OF CHAR))
          END;

    { user workfile stuff }
    INFOREC = RECORD
                SYMFIBP, CODEFIBP: FIBP;         { workfiles for scratch }
                ERRSYM, ERRBLK, ERRNUM: INTEGER; { error stuff in edit }
                SLOWTERM, STUPID: BOOLEAN;
                ALTMODE: CHAR;                   { washout char, compiler }
                GOTSYM, GOTCODE: BOOLEAN;        { titles are meaningful }
                WORKVID, SYMVID, CODEVID: VID;
                WORKTID, SYMTID, CODETID: TID
              END;

    { code segment layouts }
    SEG_RANGE = 0..MAX_SEG;
    SEG_DESC = RECORD
                 DISKADDR: INTEGER;  { rel blk in code, abs in SYSCOM^ }
                 CODELENG: INTEGER   { # bytes to read in }
               END;

    { debugger stuff }
    BYTERANGE = 0..255;
    TRICKARRAY = RECORD              { memory diddling for EXECERROR }
                   CASE BOOLEAN OF
                     TRUE: (WORD: ARRAY [0..0] OF INTEGER);
                     FALSE: (BYTE: PACKED ARRAY [0..0] OF BYTERANGE)
                 END;
    MSCWP = ^MSCW;                   { mark stack record pointer }
    MSCW = RECORD
             STATLINK: MSCWP;        { pointer to parent MSCW }
             DYNLINK: MSCWP;         { pointer to caller's MSCW }
             MSSEG, MSJTAB: ^TRICKARRAY;
             MSIPC: INTEGER;
             LOCALDATA: TRICKARRAY
           END;

    { system communication area -- see interpreters. NB backward field
      allocation is assumed. }
    SEG_ENTRY = RECORD
                  CODEUNIT: UNITNUM;
                  CODEDESC: SEG_DESC
                END;
    SYSCOMREC = RECORD
                  IORSLT: IORSLTWD;   { result of last IO call }
                  XEQERR: INTEGER;    { reason for EXECERROR call }
                  SYSUNIT: UNITNUM;   { physical unit of bootload }
                  BUGSTATE: INTEGER;  { debugger info }
                  GDIRP: DIRP;        { global dir pointer, see VOLSEARCH }
                  LASTMP, STKBASE, BOMBP: MSCWP;
                  MEMTOP, SEG, JTAB: INTEGER;
                  BOMBIPC: INTEGER;   { where EXECERROR blowup was }
                  HLTLINE: INTEGER;   { more debugger stuff }
                  BRKPTS: ARRAY [0..3] OF INTEGER;
                  RETRIES: INTEGER;   { drivers put retry counts }
                  EXPANSION: ARRAY [0..8] OF INTEGER;
                  HIGHTIME, LOWTIME: INTEGER;
                  MISCINFO: PACKED RECORD
                              NOBREAK, STUPID, SLOWTERM,
                              HASXYCRT, HASLCCRT, HAS8510A, HASCLOCK: BOOLEAN;
                              USERKIND: (NORMAL, AQUIZ, BOOKER, PQUIZ);
                              WORD_MACH, IS_FLIPT: BOOLEAN
                            END;
                  CRTTYPE: INTEGER;
                  CRTCTRL: PACKED RECORD
                             RLF, NDFS, ERASEEOL, ERASEEOS, HOME,
                             ESCAPE: CHAR;
                             BACKSPACE: CHAR;
                             FILLCOUNT: 0..255;
                             CLEARSCREEN, CLEARLINE: CHAR;
                             PREFIXED: PACKED ARRAY [0..15] OF BOOLEAN
                           END;
                  CRTINFO: PACKED RECORD
                             WIDTH, HEIGHT: INTEGER;
                             RIGHT, LEFT, DOWN, UP: CHAR;
                             BADCH, CHARDEL, STOP, BREAK, FLUSH, EOF: CHAR;
                             ALTMODE, LINEDEL: CHAR;
                             ALPHA_LOCK, ETX, PREFIX: CHAR;
                             PREFIXED: PACKED ARRAY [0..15] OF BOOLEAN
                           END;
                  SEGTABLE: ARRAY [SEG_RANGE] OF SEG_ENTRY
                END;

  VAR
    SYSCOM: ^SYSCOMREC;              { offset 1 -- confirmed against
                                        FGOTOXY's own real body: it
                                        clamps X/Y against a pointer set
                                        to SYSCOM+37, which lands exactly
                                        on CRTINFO.WIDTH (the next field,
                                        HEIGHT, clamps the other axis) }
    GFILES: ARRAY [0..5] OF FIBP;    { offsets 2-7. GFILES[1] (offset 3)
                                        is what every segment-0 body's
                                        own FWRITESTRING/FWRITELN call
                                        actually writes through -- not a
                                        separate OUTPUTFIB, confirmed by
                                        the same offset math (SYSCOM=1,
                                        GFILES[0]=2, GFILES[1]=3, zero
                                        reordering needed against UCSD's
                                        own literal declaration order).
                                        0=INPUT, 1=OUTPUT (GLOBALS.TEXT's
                                        own comment) }
    USERINFO: INFOREC;               { work stuff for compiler etc }
    EMPTYHEAP: ^INTEGER;             { heap mark for mem managing }
    INPUTFIB, OUTPUTFIB,             { console files -- GFILES are copies }
    SYSTERM, SWAPFIB: FIBP;          { control and swapspace files }
    SYVID, DKVID: VID;               { SYSUNIT volid & default volid }
    THEDATE: DATEREC;                { today -- set in FILER or sign-on }
    DEBUGINFO: ^INTEGER;             { debugger's global info while running }
    STATE: CMDSTATE;                 { for GETCOMMAND }
    PL: STRING;                      { prompt-line string, see PROMPT }
    IPOT: ARRAY [0..4] OF INTEGER;   { integer powers of ten }
    FILLER: STRING[FILL_LEN];        { nulls for carriage delay }
    DIGITS: SET OF '0'..'9';
    UNITABLE: ARRAY [UNITNUM] OF     { 0 not used }
                RECORD
                  UVID: VID;
                  CASE UISBLKD: BOOLEAN OF
                    TRUE: (UEOVBLK: INTEGER)
                END;
    FILENAME: FILE_TABLE;

    { `FPNEWBLK` = `FILEPROC.2` (finding 168), `FPRESET`'s own nested
      helper -- decoded from its addressed real disassembly. Advances
      `F` past a block boundary: clears `FREPTCNT`/`FEOF`/`FEOLN`,
      then (block-device files only) raises `FMAXBLK` if `FNXTBLK` has
      gone past it, and (soft-buffered files only) flushes a changed
      in-memory buffer to disk via `UNITWRITE` -- zero-padding its tail
      with `FILLCHAR` first when at a fresh high-water block, and (for
      `TEXTFILE`s specifically, at a boundary) writing a second,
      freshly-zeroed block immediately after and bumping `FMAXBLK`
      again. Resets `FNXTBLK` to `0` (or `2`, for a soft-buffered
      `TEXTFILE`) at the end either way. `IORSLT`-style bookkeeping and
      absolute-block arithmetic (`FHEADER.DFIRSTBLK + FNXTBLK`, `-1`
      for the just-finished block vs. none for the new one) mirror the
      same idiom `STUB49` already established (finding 165). Compiles
      clean; `params=2` bytes exact, `locals=2` against the real `4` --
      two bytes (one word) short, documented not forced. }
    PROCEDURE FPNEWBLK(VAR F: FIB);
      VAR
        ATBOUNDARY: BOOLEAN;
    BEGIN
      F.FREPTCNT := 0;
      F.FEOLN := FALSE;
      F.FEOF := FALSE;
      IF F.FISBLKD THEN
      BEGIN
        ATBOUNDARY := F.FNXTBLK > F.FMAXBLK;
        IF ATBOUNDARY THEN F.FMAXBLK := F.FNXTBLK;
        IF F.FSOFTBUF THEN
        BEGIN
          IF ATBOUNDARY THEN
            F.FNXTBYTE := F.FMAXBYTE
          ELSE IF (F.FNXTBLK = F.FMAXBLK) AND (F.FMAXBYTE >= F.FNXTBYTE) THEN
          BEGIN
            ATBOUNDARY := TRUE;
            F.FNXTBYTE := F.FMAXBYTE
          END;
          IF F.FBUFCHNGD THEN
          BEGIN
            F.FBUFCHNGD := FALSE;
            F.FMODIFIED := TRUE;
            IF ATBOUNDARY THEN
              FILLCHAR(F.FBUFFER[F.FMAXBYTE], 512 - F.FMAXBYTE, CHR(0));
            UNITWRITE(F.FUNIT, F.FBUFFER[0], 512,
                      (F.FHEADER.DFIRSTBLK + F.FNXTBLK) - 1);
            IF ATBOUNDARY AND (F.FHEADER.DFKIND = TEXTFILE) AND
               (F.FNXTBLK <> 0) THEN
            BEGIN
              F.FMAXBLK := F.FMAXBLK + 1;
              FILLCHAR(F.FBUFFER[0], 512, CHR(0));
              UNITWRITE(F.FUNIT, F.FBUFFER[0], 512,
                        F.FHEADER.DFIRSTBLK + F.FNXTBLK)
            END
          END;
          F.FMAXBYTE := 512
        END;
        F.FNXTBLK := 0;
        IF F.FSOFTBUF AND (F.FHEADER.DFKIND = TEXTFILE) THEN
          F.FNXTBLK := 2
      END
    END;

    PROCEDURE FPTITLE(VAR S: STRING; SUFFIX: BOOLEAN; N: INTEGER);
      VAR
        P, L, I: INTEGER;
        BRACKET, SUFFIXSTR: STRING;
    BEGIN
      P := SPOS(' ', S);
      WHILE P > 0 DO
      BEGIN
        SDELETE(1, P, S);
        P := SPOS(' ', S)
      END;
      IF LENGTH(S) > 0 THEN
        IF S[LENGTH(S)] = '.' THEN
          S[0] := CHR(LENGTH(S) - 1)
        ELSE
        BEGIN
          BRACKET := '';
          P := SPOS('[', S);
          IF P > 0 THEN
          BEGIN
            L := (LENGTH(S) - P) + 1;
            SCOPY(L, P, S, BRACKET);
            SDELETE(L, P, S)
          END;
          IF SPOS(':', S) = 0 THEN
          BEGIN
            IF SUFFIX THEN
              SUFFIXSTR := '.CODE'
            ELSE
              SUFFIXSTR := '.TEXT';
            FOR I := 1 TO LENGTH(S) DO
            BEGIN
              IF (S[I] >= 'a') AND (S[I] <= 'z') THEN
                S[I] := CHR(ORD(S[I]) - 32);
              IF S[I] < ' ' THEN
                S[I] := '?'
            END;
            IF (N - LENGTH(S)) >= 5 THEN
              SCONCAT(N, S, SUFFIXSTR);
            SCONCAT(N, S, BRACKET)
          END
        END
    END;

  PROCEDURE BLKXFER(UNITNO: INTEGER; BUFADDR: WINDOWP; BYTEOFS: INTEGER;
                        NBLOCKS: INTEGER; BLOCKNUM: INTEGER; DOREAD: BOOLEAN);
    VAR
      NB, LEN: INTEGER;
  BEGIN
    IF NBLOCKS > 63 THEN NB := 63 ELSE NB := NBLOCKS;
    LEN := NB * 512;
    WHILE NBLOCKS <> 0 DO
    BEGIN
      IF DOREAD THEN
        UNITREAD(UNITNO, BUFADDR^[BYTEOFS], LEN, BLOCKNUM)
      ELSE
        UNITWRITE(UNITNO, BUFADDR^[BYTEOFS], LEN, BLOCKNUM);
      IF IORESULT <> 0 THEN EXIT(BLKXFER);
      NBLOCKS := NBLOCKS - NB;
      BYTEOFS := BYTEOFS + LEN;
      BLOCKNUM := BLOCKNUM + NB;
      IF NBLOCKS < NB THEN NB := NBLOCKS;
      LEN := NB * 512
    END
  END;

  FUNCTION FBLOCKIO;
  BEGIN
    FBLOCKIO := 0;
    IF F.FISOPEN AND (NBLOCKS >= 0) THEN
      IF F.FISBLKD THEN
      BEGIN
        IF RBLOCK < 0 THEN RBLOCK := F.FNXTBLK;
        RBLOCK := RBLOCK + F.FHEADER.DFIRSTBLK;
        IF RBLOCK + NBLOCKS > F.FHEADER.DLASTBLK THEN
          IF NOT DOREAD THEN
            IF STUB49(F) THEN ;
        IF RBLOCK + NBLOCKS > F.FHEADER.DLASTBLK THEN
          NBLOCKS := F.FHEADER.DLASTBLK - RBLOCK;
        F.FEOF := RBLOCK >= F.FHEADER.DLASTBLK;
        IF NOT F.FEOF THEN
        BEGIN
          BLKXFER(F.FUNIT, @A, I, NBLOCKS, RBLOCK, DOREAD);
          IF IORESULT = 0 THEN
          BEGIN
            IF NOT DOREAD THEN F.FMODIFIED := TRUE;
            FBLOCKIO := NBLOCKS;
            RBLOCK := RBLOCK + NBLOCKS;
            F.FEOF := RBLOCK = F.FHEADER.DLASTBLK;
            F.FNXTBLK := RBLOCK - F.FHEADER.DFIRSTBLK;
            IF F.FNXTBLK > F.FMAXBLK THEN F.FMAXBLK := F.FNXTBLK
          END
        END
      END
      ELSE
      BEGIN
        FBLOCKIO := NBLOCKS;
        BLKXFER(F.FUNIT, @A, I, NBLOCKS, RBLOCK, DOREAD);
        IF IORESULT <> 0 THEN
          FBLOCKIO := 0
        ELSE
          IF DOREAD THEN
          BEGIN
            RBLOCK := NBLOCKS * 512;
            RBLOCK := RBLOCK + SCAN(-RBLOCK, <>CHR(0), A[I + RBLOCK - 1]);
            RBLOCK := (RBLOCK + 512 - 1) DIV 512;
            FBLOCKIO := RBLOCK;
            F.FEOF := RBLOCK < NBLOCKS
          END
      END
  END;

  BEGIN

    BEGIN

      I: INTEGER;
      DONE, FOUND: BOOLEAN;
      NEWLAST: INTEGER;
      DIR: DIRP;
  BEGIN
    STUB49 := TRUE;
    DONE := FALSE;
    WITH F DO
      IF LENGTH(FHEADER.DVID) > 0 THEN
        WITH FHEADER DO
          IF VOLSEARCH(DVID, FALSE, DIR) <> FUNIT THEN
            SYSCOM^.IORSLT := ILOSTUNIT
          ELSE
          BEGIN
            FOUND := FALSE;
            I := 1;
            WHILE (I <= DIR^[0].DNUMFILES) AND NOT FOUND DO
            BEGIN
              FOUND := (DIR^[I].DFIRSTBLK = DFIRSTBLK) AND
                       (DIR^[I].DLASTBLK = DLASTBLK);
              I := I + 1
            END;
            IF NOT FOUND THEN
              SYSCOM^.IORSLT := ILOSTFILE
            ELSE
            BEGIN
              IF I > DIR^[0].DNUMFILES THEN
                NEWLAST := DIR^[0].DEOVBLK
              ELSE
                NEWLAST := DIR^[I].DFIRSTBLK;
              IF (DLASTBLK < NEWLAST) OR (DLASTBYTE < 512) THEN
                DONE := TRUE
              ELSE
                WITH DIR^[I - 1] DO
                BEGIN
                  DLASTBLK := NEWLAST;
                  DLASTBYTE := 512;
                  WRITEDIR(F.FUNIT, DIR);
                  IF IORESULT = 0 THEN
                  BEGIN
                    F.FEOF := FALSE;
                    F.FEOLN := FALSE;

                    F.FHEADER.DLASTBYTE := 512;
                    F.FHEADER.DACCESS.YEAR := 100;
                    STUB49 := FALSE;
                    DONE := TRUE
                  END
                END
            END
          END;
    IF DONE THEN
    BEGIN
      F.FEOF := TRUE;
      F.FEOLN := TRUE
    END
  END;
