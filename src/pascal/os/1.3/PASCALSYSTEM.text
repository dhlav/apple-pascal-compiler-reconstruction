{ SYSTEM.PASCAL -- the Apple Pascal operating system: command menu, file
  I/O primitives, error printing, initialization, and program loading.
  Codefile target is **128K.PASCAL** specifically (APPLE3:) -- the only
  build this project reads, cites, or tests against; the 64K
  `SYSTEM.PASCAL` build is out of scope entirely, by direct instruction
  (`analysis/diskset-inventory.txt` has 128K.PASCAL's own 7-segment
  layout).

  First session: the skeleton only. `PROGRAM PASCALSYSTEM` matches
  UCSD II.0's own program name exactly (`reference_source/ucsd_ii0/
  GLOBALS.TEXT`) and the shape SETUP.text's own header comment already
  worked out for a `(*$U-*)` host program wrapping `SEGMENT PROCEDURE`s
  one level in. `CONST`/`TYPE` and the VAR section below are ported
  from `GLOBALS.TEXT` (legitimate for names per the project's own
  sources-of-truth order -- UCSD source for names, re-derive structure
  from the binary) as a *starting point*, not yet verified against
  Apple's own frame sizes; `PASCALSY` (segment 0, the real 451-word
  main loop, `analysis/lifted/128K.PASCAL-1.3-128K.pas.txt`) is left a
  trivial outer body for now, deliberately deferred -- it is the single
  biggest procedure in the entire disk set and depends on getting these
  globals right first.

  **`WRITE`/`WRITELN` do not work here -- call `FWRITESTRING`/
  `FWRITELN`/etc. directly.** UCSD's own source does exactly that
  (`SYSSEGS.A.TEXT`'s `FWRITELN(SYSTERM^)`, not `WRITELN(SYSTERM^)`),
  and it turns out to be load-bearing, not stylistic: `WRITE`/`WRITELN`
  compile to these same routines as compiler sugar, but Apple's own
  compiler only accepts a *plain variable identifier* as that sugar's
  file argument -- `WRITELN(SYSTERM^)` (a pointer dereference, not an
  identifier) hits error 125 on Apple's real compiler even though the
  host compiler (`ucsdpsys_compile`) accepts it, one more case of the
  host tool being more permissive than Apple's (confirmed both ways
  directly: `WRITELN(SYSTERM^)` fails, `WRITELN(DIRECTF)` on a plain
  `TEXT` variable of the same type succeeds). Calling `FWRITELN`
  directly sidesteps the restriction entirely -- it is an ordinary
  procedure call, not compiler sugar, and ordinary `VAR` parameters
  accept any suitable expression, dereferences included. This is also
  why `FIB`, not `TEXT`, is `FWRITELN`'s own real parameter type
  (`GLOBALS.TEXT`'s own forward declaration, `PROCEDURE
  FWRITELN(VAR F: FIB); FORWARD;`) -- confirmed against the raw p-code
  too: `USERPROG.1` pushes `LOD 1,56` (a plain value load, not a
  dereference-then-load) straight into `CXP 0,22` (`OS.22`, i.e.
  segment-0 procedure 22 -- `FWRITELN`), meaning the real global at
  that offset is itself the pointer, loaded and passed as-is.

  That single fact reshaped this file: `GLOBALS.TEXT`'s own "SYSTEM
  PROCEDURE FORWARD DECLARATIONS" section (27 "fixed", addressed
  directly by object code, then 14 "non-fixed") is not a documentation
  aid, it is 41 of segment 0's own procedure declarations, and segment
  0's own body (`PASCALSY.1`, deferred) makes 42 -- exactly finding
  51a's own already-verified count for how far Apple's segment-0
  numbering agrees with UCSD's declared order. Declaring all 41 here,
  in this same order, before any `SEGMENT PROCEDURE`, lands their
  procedure *numbers* right even though every body but the two below
  is still a stub: `FINIT` (2nd declared) already matches an
  independently-recovered comment from earlier compiler work, `OS.3
  FINIT` -- procedure 3, one more than its declaration position because
  the enclosing block's own body always claims number 1.

  `USERPROGRAM` (segment 1, `USERPROG` on disk) is the one real body
  this session: UCSD's own `SYSSEGS.A.TEXT` gives it verbatim (once
  written as direct `FWRITELN`/`FWRITESTRING` calls, per above), and
  Apple's binary (`args 2 words`) matches UCSD's own 2-parameter
  declaration exactly -- unlike segment 0's own procedures 43 onward
  (finding 51c), this one is a straight, unmodified port. The other
  five segments are stubs: `PRINTERROR(XEQERR,IORSLT: INTEGER)`,
  `INITIALIZE`, and `GETCMD(LASTST: CMDSTATE): CMDSTATE` all match
  Apple's own real `args` word counts exactly against UCSD's declared
  signatures (`params=2/1/1` respectively, `analysis/lifted/
  128K.PASCAL-1.3-128K.pas.txt`), so those signatures are trusted;
  `FIOPRIMS` (`args 0 words`, real) and `FILEPROC` (`args 6 words`,
  real) have no UCSD precedent at all -- Apple-specific segments, most
  likely 128K-only code the 64K system keeps inline in segment 0.
  `FILEPROC`'s own six words dispatch on the first (`OP`) to one of
  several internal arms, mapped directly from the real binary's own
  `FILEPROC` segment (finding 156) -- `VAR F: FIB`, `VAR ARGSTR:
  STRING`, `ARGBOOL: BOOLEAN`, `ARGPTR: FIBP`, `ARGINT: INTEGER`. }

PROGRAM PASCALSYSTEM;

  CONST
    MMAXINT  = 32767;  { maximum INTEGER value }
    MAXUNIT  = 20;      { maximum physical unit # for UREAD -- UCSD
                          II.0's own GLOBALS.TEXT says 12 (1.1's own
                          value), but Neil Parker's own documented
                          DISKNUM table (evidence/reference/
                          "Undocumented Secrets of Apple Pascal.html")
                          says the OS's own internal table is "12
                          (Apple Pascal 1.1) or 20 (Apple Pascal 1.2
                          and 1.3)" -- 1.3 real, not UCSD generic }
    MAXDIR   = 77;      { max number of entries in a directory }
    VIDLENG  = 7;       { number of chars in a volume ID }
    TIDLENG  = 15;      { number of chars in a title ID }
    MAX_SEG  = 63;      { max code segment number -- 31 for the 64K
                          system, 63 for the 128K system (Neil Parker,
                          "Undocumented Secrets of Apple Pascal");
                          this build targets 128K.PASCAL }
    FBLKSIZE = 512;     { standard disk block length }
    DIRBLK   = 2;       { disk addr of the directory }
    AGELIMIT = 300;     { max age for GDIRP, in ticks }
    EOL      = 13;      { end-of-line -- ASCII CR }
    DLE      = 16;      { blank-compression code }
    NAME_LEN = 23;      { CONCAT(VIDLENG, ':', TIDLENG) }
    FILL_LEN = 11;      { max # of nulls in FILLER }

  TYPE
    IORSLTWD = (INOERROR, IBADBLOCK, IBADUNIT, IBADMODE, ITIMEOUT,
                ILOSTUNIT, ILOSTFILE, IBADTITLE, INOROOM, INOUNIT,
                INOFILE, IDUPFILE, INOTCLOSED, INOTOPEN, IBADFORMAT,
                ISTRGOVFL);

    { command states -- see GETCMD }
    CMDSTATE = (HALTINIT, DEBUGCALL,
                UPROGNOU, UPROGUOK, SYSPROG,
                COMPONLY, COMPANDGO, COMPDEBUG,
                LINKANDGO, LINKDEBUG);

    { code files used in GETCMD }
    SYSFILE = (ASSMBLER, COMPILER, EDITOR, FILER, LINKER);

    { archival info -- the date }
    DATEREC = PACKED RECORD
                MONTH: 0..12;  { 0 implies date not meaningful }
                DAY: 0..31;
                YEAR: 0..100   { 100 is temp-disk flag }
              END;

    { volume tables }
    UNITNUM = 0..MAXUNIT;
    VID = STRING[VIDLENG];

    { disk directories }
    DIRRANGE = 0..MAXDIR;
    TID = STRING[TIDLENG];
    FULL_ID = STRING[NAME_LEN];

    FILE_TABLE = ARRAY [SYSFILE] OF FULL_ID;

    FILEKIND = (UNTYPEDFILE, XDSKFILE, CODEFILE, TEXTFILE,
                INFOFILE, DATAFILE, GRAFFILE, FOTOFILE, SECUREDIR);

    DIRENTRY = PACKED RECORD
                 DFIRSTBLK: INTEGER;  { first physical disk addr }
                 DLASTBLK: INTEGER;   { points at block following }
                 CASE DFKIND: FILEKIND OF
                   SECUREDIR,
                   UNTYPEDFILE:       { only in DIR[0] -- volume info }
                     (FILLER1: 0..2048;
                      DVID: VID;
                      DEOVBLK: INTEGER;
                      DNUMFILES: DIRRANGE;
                      DLOADTIME: INTEGER;
                      DLASTBOOT: DATEREC);
                   XDSKFILE, CODEFILE, TEXTFILE, INFOFILE,
                   DATAFILE, GRAFFILE, FOTOFILE:
                     (FILLER2: 0..1024;
                      STATUS: BOOLEAN;   { for FILER wildcards }
                      DTID: TID;
                      DLASTBYTE: 1..FBLKSIZE;
                      DACCESS: DATEREC)
               END;

    DIRP = ^DIRECTORY;
    DIRECTORY = ARRAY [DIRRANGE] OF DIRENTRY;

    { file information }
    CLOSETYPE = (CNORMAL, CLOCK, CPURGE, CCRUNCH);
    WINDOWP = ^WINDOW;
    WINDOW = PACKED ARRAY [0..0] OF CHAR;


    FIBP = ^FIB;

    FIB = RECORD
            FWINDOW: WINDOWP;  { user window, F^, used by GET/PUT }
            FEOF, FEOLN: BOOLEAN;
            FSTATE: (FJANDW, FNEEDCHAR, FGOTCHAR);
            FRECSIZE: INTEGER; { bytes; 0=>block file, 1=>char file }
            CASE FISOPEN: BOOLEAN OF
              TRUE: (FISBLKD: BOOLEAN;   { file is on a block device }
                     FUNIT: UNITNUM;
                     FVID: VID;
                     FREPTCNT,          { # times F^ valid w/o GET }
                     FNXTBLK,           { next rel block to IO }
                     FMAXBLK: INTEGER;  { max rel block accessed }
                     FMODIFIED: BOOLEAN;
                     FHEADER: DIRENTRY; { copy of disk dir entry }
                     CASE FSOFTBUF: BOOLEAN OF
                       TRUE: (FNXTBYTE, FMAXBYTE: INTEGER;
                              FBUFCHNGD: BOOLEAN;
                              FBUFFER: PACKED ARRAY [0..FBLKSIZE] OF CHAR))
          END;

    { user workfile stuff }
    INFOREC = RECORD
                SYMFIBP, CODEFIBP: FIBP;         { workfiles for scratch }
                ERRSYM, ERRBLK, ERRNUM: INTEGER; { error stuff in edit }
                SLOWTERM, STUPID: BOOLEAN;
                ALTMODE: CHAR;                   { washout char, compiler }
                GOTSYM, GOTCODE: BOOLEAN;        { titles are meaningful }
                WORKVID, SYMVID, CODEVID: VID;
                WORKTID, SYMTID, CODETID: TID
              END;

    { code segment layouts }
    SEG_RANGE = 0..MAX_SEG;
    SEG_DESC = RECORD
                 DISKADDR: INTEGER;  { rel blk in code, abs in SYSCOM^ }
                 CODELENG: INTEGER   { # bytes to read in }
               END;

    { debugger stuff }
    BYTERANGE = 0..255;
    TRICKARRAY = RECORD              { memory diddling for EXECERROR }
                   CASE BOOLEAN OF
                     TRUE: (WORD: ARRAY [0..0] OF INTEGER);
                     FALSE: (BYTE: PACKED ARRAY [0..0] OF BYTERANGE)
                 END;
    MSCWP = ^MSCW;                   { mark stack record pointer }
    MSCW = RECORD
             STATLINK: MSCWP;        { pointer to parent MSCW }
             DYNLINK: MSCWP;         { pointer to caller's MSCW }
             MSSEG, MSJTAB: ^TRICKARRAY;
             MSIPC: INTEGER;
             LOCALDATA: TRICKARRAY
           END;

    { system communication area -- see interpreters. NB backward field
      allocation is assumed. }
    SEG_ENTRY = RECORD
                  CODEUNIT: UNITNUM;
                  CODEDESC: SEG_DESC
                END;
    SYSCOMREC = RECORD
                  IORSLT: IORSLTWD;   { result of last IO call }
                  XEQERR: INTEGER;    { reason for EXECERROR call }
                  SYSUNIT: UNITNUM;   { physical unit of bootload }
                  BUGSTATE: INTEGER;  { debugger info }
                  GDIRP: DIRP;        { global dir pointer, see VOLSEARCH }
                  LASTMP, STKBASE, BOMBP: MSCWP;
                  MEMTOP, SEG, JTAB: INTEGER;
                  BOMBIPC: INTEGER;   { where EXECERROR blowup was }
                  HLTLINE: INTEGER;   { more debugger stuff }
                  BRKPTS: ARRAY [0..3] OF INTEGER;
                  RETRIES: INTEGER;   { drivers put retry counts }
                  EXPANSION: ARRAY [0..8] OF INTEGER;
                  HIGHTIME, LOWTIME: INTEGER;
                  MISCINFO: PACKED RECORD
                              NOBREAK, STUPID, SLOWTERM,
                              HASXYCRT, HASLCCRT, HAS8510A, HASCLOCK: BOOLEAN;
                              USERKIND: (NORMAL, AQUIZ, BOOKER, PQUIZ);
                              WORD_MACH, IS_FLIPT: BOOLEAN
                            END;
                  CRTTYPE: INTEGER;
                  CRTCTRL: PACKED RECORD
                             RLF, NDFS, ERASEEOL, ERASEEOS, HOME,
                             ESCAPE: CHAR;
                             BACKSPACE: CHAR;
                             FILLCOUNT: 0..255;
                             CLEARSCREEN, CLEARLINE: CHAR;
                             PREFIXED: PACKED ARRAY [0..15] OF BOOLEAN
                           END;
                  CRTINFO: PACKED RECORD
                             WIDTH, HEIGHT: INTEGER;
                             RIGHT, LEFT, DOWN, UP: CHAR;
                             BADCH, CHARDEL, STOP, BREAK, FLUSH, EOF: CHAR;
                             ALTMODE, LINEDEL: CHAR;
                             ALPHA_LOCK, ETX, PREFIX: CHAR;
                             PREFIXED: PACKED ARRAY [0..15] OF BOOLEAN
                           END;
                  SEGTABLE: ARRAY [SEG_RANGE] OF SEG_ENTRY
                END;

  VAR
    SYSCOM: ^SYSCOMREC;              { offset 1 -- confirmed against
                                        FGOTOXY's own real body: it
                                        clamps X/Y against a pointer set
                                        to SYSCOM+37, which lands exactly
                                        on CRTINFO.WIDTH (the next field,
                                        HEIGHT, clamps the other axis) }
    GFILES: ARRAY [0..5] OF FIBP;    { offsets 2-7. GFILES[1] (offset 3)
                                        is what every segment-0 body's
                                        own FWRITESTRING/FWRITELN call
                                        actually writes through -- not a
                                        separate OUTPUTFIB, confirmed by
                                        the same offset math (SYSCOM=1,
                                        GFILES[0]=2, GFILES[1]=3, zero
                                        reordering needed against UCSD's
                                        own literal declaration order).
                                        0=INPUT, 1=OUTPUT (GLOBALS.TEXT's
                                        own comment) }
    USERINFO: INFOREC;               { work stuff for compiler etc }
    EMPTYHEAP: ^INTEGER;             { heap mark for mem managing }
    INPUTFIB, OUTPUTFIB,             { console files -- GFILES are copies }
    SYSTERM, SWAPFIB: FIBP;          { control and swapspace files }
    SYVID, DKVID: VID;               { SYSUNIT volid & default volid }
    THEDATE: DATEREC;                { today -- set in FILER or sign-on }
    DEBUGINFO: ^INTEGER;             { debugger's global info while running }
    STATE: CMDSTATE;                 { for GETCOMMAND }
    PL: STRING;                      { prompt-line string, see PROMPT }
    IPOT: ARRAY [0..4] OF INTEGER;   { integer powers of ten }
    FILLER: STRING[FILL_LEN];        { nulls for carriage delay }
    DIGITS: SET OF '0'..'9';
    UNITABLE: ARRAY [UNITNUM] OF     { 0 not used }
                RECORD
                  UVID: VID;
                  CASE UISBLKD: BOOLEAN OF
                    TRUE: (UEOVBLK: INTEGER)
                END;
    FILENAME: FILE_TABLE;

  SEGMENT PROCEDURE FIOPRIMS;

    { `FIOPRIMS.2` -- soft-buffer window advance (finding 174, closing
      finding 170's own standing gap). Copies up to `FRECSIZE` bytes
      from the in-memory soft buffer into the user's window (`F^`),
      pulling in fresh disk blocks via `UNITREAD` as needed and flushing
      a dirty buffer via `UNITWRITE` first when one is pending. `ROOM`
      is computed one of two ways depending on whether `FNXTBLK` is
      still short of `FMAXBLK` (already-known blocks ahead -- use the
      full `512`) or at/past it (the file's last known block -- use
      `FHEADER.DLASTBYTE`, the true end of valid data, and give up with
      no advance at all if even one more record would run past
      `FNXTBYTE`, the real `EOF` case). `NEED` clamps `RECSIZE` to
      `ROOM`; a `MOVELEFT` copies what's available this pass and updates
      `FNXTBYTE`/`WINOFS`/`RECSIZE`; if `RECSIZE` isn't yet `0`, the loop
      writes back a dirty block, reads the next one, and retries.
      Result is `TRUE` only on the genuine-`EOF`/`IORESULT`-error exits
      (via `GOTO`, matching the real binary's own jump table entry for
      an early return past the trailing `FPWINADV := FALSE`); `FALSE`
      once the loop's own natural exit is reached, `RECSIZE = 0`.

      Two systematic gaps, not forced: the real binary caches `F`'s own
      address into a *second* local (`STL 9`) even though it's already
      a trivially-addressable `VAR` parameter, on top of the expected
      `FHEADER` cache -- the same `WITH F DO WITH FHEADER DO` idiom used
      successfully elsewhere in this file (`STUB49`, finding 165) still
      doesn't reproduce that extra, semantically-redundant caching
      step under this host compiler; `params=6` bytes exact, `locals=12`
      against the real `14`, two words short from this alone.

      Separately: `DIRENTRY.DLASTBYTE` is declared `1..FBLKSIZE`
      (`1..512`, needing all 10 bits) and this host compiler always
      compiles any access to it as a packed load/store (`LDP`/`STP`,
      confirmed by an isolated probe compiling `D.DLASTBYTE := 5` in
      total isolation) -- but the real binary's own `FHEADER.DLASTBYTE`
      read here is a plain unpacked `IND`/`STO`, no `LDP` anywhere
      nearby. `DLASTBYTE` doesn't share a word with any neighboring
      field in this variant (`STATUS` and `DACCESS` are packed
      separately), so Apple's own compiler evidently doesn't bother
      packing a subrange into fewer than its natural word when doing so
      saves nothing -- a real compiler-behavior divergence from this
      host tool, not a source-level choice available to fix. Any other
      already-written `DLASTBYTE` reference in this file (`STUB49`,
      `FPCLOSE`) carries the same latent, previously-undetected gap. }
    FUNCTION FPWINADV(VAR F: FIB): BOOLEAN;
      LABEL 1;
      VAR
        RECSIZE, WINOFS, ROOM, NEED: INTEGER;
        FILLED: BOOLEAN;
    BEGIN
      FPWINADV := TRUE;
      WITH F DO
        WITH FHEADER DO
        BEGIN
          RECSIZE := FRECSIZE;
          WINOFS := 0;
          REPEAT
            IF FNXTBLK >= FMAXBLK THEN
            BEGIN
              IF (FNXTBYTE + RECSIZE) > FMAXBYTE THEN GOTO 1;
              ROOM := DLASTBYTE - FNXTBYTE
            END
            ELSE
              ROOM := 512 - FNXTBYTE;
            NEED := RECSIZE;
            IF NEED > ROOM THEN NEED := ROOM;
            IF NEED > 0 THEN
            BEGIN
              MOVELEFT(FBUFFER[FNXTBYTE], FWINDOW^[WINOFS], NEED);
              FNXTBYTE := FNXTBYTE + NEED;
              WINOFS := WINOFS + NEED;
              RECSIZE := RECSIZE - NEED
            END;
            FILLED := RECSIZE = 0;
            IF NOT FILLED THEN
            BEGIN
              IF FBUFCHNGD THEN
              BEGIN
                FBUFCHNGD := FALSE;
                FMODIFIED := TRUE;
                UNITWRITE(FUNIT, FBUFFER[0], 512, DFIRSTBLK + FNXTBLK - 1)
              END;
              IF IORESULT <> 0 THEN GOTO 1;
              UNITREAD(FUNIT, FBUFFER[0], 512, DFIRSTBLK + FNXTBLK);
              IF IORESULT <> 0 THEN GOTO 1;
              FNXTBLK := FNXTBLK + 1;
              FNXTBYTE := 0
            END
          UNTIL FILLED;
          FPWINADV := FALSE
        END;
      1: ;
    END;

    { `FIOPRIMS.3` -- DLE-blank expansion (finding 171). Called by
      `FGET` only right after reading a literal `DLE` (`16`) byte, per
      `FGET`'s own gate. Reads the *next* byte (the two-byte DLE code's
      count, `+32`, this file's own already-quoted manual comment on
      `DLE`-blank codes); if it's a real character (`> ' '`) rather
      than a valid count byte, treats the `DLE` as spurious, reads past
      it, and reports `FALSE` (no compression applied). Otherwise loads
      `F.FREPTCNT` with the decoded blank count and replaces the window
      byte with a space -- `FGET`'s own opening guard (`IF F.FREPTCNT >
      0 THEN` decrement and return early, no real read) is exactly what
      consumes this: each of the next `FREPTCNT` `GET`s just replays
      the cached space with no further I/O. Compiles clean, `params=6`
      bytes exact; `locals=0` against the real `2` -- one word short
      (the real body caches `F` into a local, this one dereferences
      `F.FWINDOW` directly instead), documented not forced. }
    FUNCTION FPDLE(VAR F: FIB): BOOLEAN;
    BEGIN
      FGET(F);
      IF F.FWINDOW^[0] > ' ' THEN
      BEGIN
        FGET(F);
        FPDLE := FALSE
      END
      ELSE
      BEGIN
        F.FREPTCNT := ORD(F.FWINDOW^[0]) - 32;
        F.FWINDOW^[0] := ' ';
        FPDLE := TRUE
      END
    END;

    { `FIOPRIMS.4` -- speculative lookahead `GET` with rollback
      (finding 171). Snapshots the *entire* `FIB` (a plain record
      assignment compiles to exactly the real binary's own `MOV 290`
      -- confirmed by an isolated probe before trusting it, not assumed
      from the locals count alone), advances `FNXTBLK` and sets
      `FMAXBYTE` to look one record ahead, then calls `FGET` for real.
      If that hits real `EOF`, rolls the whole `FIB` back to the
      snapshot (undoing the speculative advance) and marks
      `FEOF`/`FEOLN` true with `FMAXBYTE` backed off by one -- a
      lookahead specifically for `TEXTFILE` `EOLN` detection (matches
      `FGET`'s own gate: `FSOFTBUF AND (DFKIND = TEXTFILE)`). Compiles
      clean, `params=2` bytes exact; `locals` is dominated by the
      290-word `FIB` snapshot itself, matching the real binary's own
      huge `locals=582` almost exactly (`580` here, two bytes short --
      the same one-word-ish gap class as this file's other close
      matches). }
    PROCEDURE FPPEEK(VAR F: FIB);
      VAR
        SAVE: FIB;
    BEGIN
      SAVE := F;
      IF F.FNXTBLK <> 0 THEN F.FNXTBLK := F.FNXTBLK + 1;
      F.FMAXBYTE := 512;
      FGET(F);
      IF F.FEOF THEN
      BEGIN
        F := SAVE;
        F.FEOF := TRUE;
        F.FEOLN := TRUE;
        F.FMAXBYTE := F.FMAXBYTE - 1
      END
    END;

    { `FPNEWBLK` = `FILEPROC.2` (finding 168), `FPRESET`'s own nested
      helper -- decoded from its addressed real disassembly. Advances
      `F` past a block boundary: clears `FREPTCNT`/`FEOF`/`FEOLN`,
      then (block-device files only) raises `FMAXBLK` if `FNXTBLK` has
      gone past it, and (soft-buffered files only) flushes a changed
      in-memory buffer to disk via `UNITWRITE` -- zero-padding its tail
      with `FILLCHAR` first when at a fresh high-water block, and (for
      `TEXTFILE`s specifically, at a boundary) writing a second,
      freshly-zeroed block immediately after and bumping `FMAXBLK`
      again. Resets `FNXTBLK` to `0` (or `2`, for a soft-buffered
      `TEXTFILE`) at the end either way. `IORSLT`-style bookkeeping and
      absolute-block arithmetic (`FHEADER.DFIRSTBLK + FNXTBLK`, `-1`
      for the just-finished block vs. none for the new one) mirror the
      same idiom `STUB49` already established (finding 165). Compiles
      clean; `params=2` bytes exact, `locals=2` against the real `4` --
      two bytes (one word) short, documented not forced. }
    PROCEDURE FPNEWBLK(VAR F: FIB);
      VAR
        ATBOUNDARY: BOOLEAN;
    BEGIN
      F.FREPTCNT := 0;
      F.FEOLN := FALSE;
      F.FEOF := FALSE;
      IF F.FISBLKD THEN
      BEGIN
        ATBOUNDARY := F.FNXTBLK > F.FMAXBLK;
        IF ATBOUNDARY THEN F.FMAXBLK := F.FNXTBLK;
        IF F.FSOFTBUF THEN
        BEGIN
          IF ATBOUNDARY THEN
            F.FNXTBYTE := F.FMAXBYTE
          ELSE IF (F.FNXTBLK = F.FMAXBLK) AND (F.FMAXBYTE >= F.FNXTBYTE) THEN
          BEGIN
            ATBOUNDARY := TRUE;
            F.FNXTBYTE := F.FMAXBYTE
          END;
          IF F.FBUFCHNGD THEN
          BEGIN
            F.FBUFCHNGD := FALSE;
            F.FMODIFIED := TRUE;
            IF ATBOUNDARY THEN
              FILLCHAR(F.FBUFFER[F.FMAXBYTE], 512 - F.FMAXBYTE, CHR(0));
            UNITWRITE(F.FUNIT, F.FBUFFER[0], 512,
                      (F.FHEADER.DFIRSTBLK + F.FNXTBLK) - 1);
            IF ATBOUNDARY AND (F.FHEADER.DFKIND = TEXTFILE) AND
               (F.FNXTBLK <> 0) THEN
            BEGIN
              F.FMAXBLK := F.FMAXBLK + 1;
              FILLCHAR(F.FBUFFER[0], 512, CHR(0));
              UNITWRITE(F.FUNIT, F.FBUFFER[0], 512,
                        F.FHEADER.DFIRSTBLK + F.FNXTBLK)
            END
          END;

      { `FPALLOC` = `FILEPROC.5`, `FPOPEN`'s own nested free-space
        search (finding 175, body written per finding 176). Given a new
        file's name/kind/requested size and the directory to search,
        finds where to put it and inserts the entry via `INSENTRY`,
        returning the chosen index (`0` on failure). Two totally
        different algorithms depending on `FSIZE`'s sign at entry:

        - `FSIZE > 0` (an explicit size, `NAME.CODE[nnn]`): a plain
          first-fit scan over `1..DNUMFILES`, taking the first gap
          (`DFIRSTBLK[i] - DLASTBLK[i-1]`) at least `FSIZE` blocks wide.
        - `FSIZE <= 0` (`[*]`, or no size given): `FPGAP` (below) tracks
          the *two* largest gaps across the whole directory (including
          the gap after the last file, up to the volume's own
          `DEOVBLK`); the final choice is the second-largest gap if
          it's at least half the largest, else half the largest
          (rounded up) -- this project's own `CLAUDE.md` already
          documents this exact algorithm as UCSD's `[*]` file-size
          rule ("reserves the second-largest contiguous area, or half
          the largest, whichever is more"), a real independent
          confirmation that this reading is right, not just plausible.

        A full `DNUMFILES = 77` directory (this project's own
        already-documented 77-file volume cap) forces failure
        (`BESTIDX := 0`) regardless of which path found a candidate.

        `FTID` is a `VAR` parameter -- not a value one -- confirmed by
        a locals-size mismatch: a value `STRING[15]` parameter costs
        the callee an 8-word local shadow copy the real binary's own
        `locals=40` doesn't have room for; making it `VAR` closes the
        gap to one word. `FPGAP`'s own three parameters, decoded from
        its real call sites, follow the parameter-list reversal rule
        (finding 175's own new memory) rather than naive push order.
        Compiles clean: `params` exact for both, **instruction count
        exact** (`177`/`25`) against the real binary for both -- the
        closest match anywhere in this whole forward-declared-far-

      FUNCTION FPALLOC(VAR FTID: TID; FSIZE: INTEGER; FKIND: FILEKIND;
                        FDIR: DIRP): DIRRANGE;
        VAR
          NUMFILES, I, BESTIDX, SECONDIDX, SECONDSIZE: INTEGER;
          NEG: BOOLEAN;
          NEWENTRY: DIRENTRY;

        PROCEDURE FPGAP(GAPIDX, GAPEND, GAPSTART: INTEGER);
          VAR GAP: INTEGER;
        BEGIN
          GAP := GAPSTART - GAPEND;
          IF GAP > FSIZE THEN
          BEGIN
            SECONDIDX := BESTIDX;
            SECONDSIZE := FSIZE;
            BESTIDX := GAPIDX;
            FSIZE := GAP
          END
          ELSE IF GAP > SECONDSIZE THEN
          BEGIN
            SECONDSIZE := GAP;
            SECONDIDX := GAPIDX
          END
        END;

      BEGIN
        NUMFILES := FDIR^[0].DNUMFILES;
        BESTIDX := 0;
        SECONDIDX := 0;
        SECONDSIZE := 0;
        IF FSIZE > 0 THEN
        BEGIN
          I := 1;
          WHILE I <= NUMFILES DO
          BEGIN
            IF (FDIR^[I].DFIRSTBLK - FDIR^[I - 1].DLASTBLK) >= FSIZE THEN
            BEGIN
              BESTIDX := I;
              I := NUMFILES
            END;
            I := I + 1
          END
        END
        ELSE
        BEGIN
          NEG := FSIZE < 0;
          I := 1;
          WHILE I <= NUMFILES DO
          BEGIN
            FPGAP(I, FDIR^[I - 1].DLASTBLK, FDIR^[I].DFIRSTBLK);
            I := I + 1
          END;
          FPGAP(NUMFILES + 1, FDIR^[NUMFILES].DLASTBLK, FDIR^[0].DEOVBLK);
          IF NEG THEN
            IF (FSIZE DIV 2) <= SECONDSIZE THEN
            BEGIN
              FSIZE := SECONDSIZE;
              BESTIDX := SECONDIDX
            END
            ELSE
              FSIZE := (FSIZE + 1) DIV 2
        END;
        IF NUMFILES = 77 THEN BESTIDX := 0;
        IF BESTIDX > 0 THEN
        BEGIN
          NEWENTRY.DFIRSTBLK := FDIR^[BESTIDX - 1].DLASTBLK;
          NEWENTRY.DLASTBLK := NEWENTRY.DFIRSTBLK + FSIZE;
          NEWENTRY.DFKIND := FKIND;
          NEWENTRY.DTID := FTID;
          NEWENTRY.DLASTBYTE := 512;
          NEWENTRY.DACCESS.MONTH := 0;
          NEWENTRY.DACCESS.DAY := 0;
          NEWENTRY.DACCESS.YEAR := 100;
          INSENTRY(NEWENTRY, BESTIDX, FDIR)
        END;
        FPALLOC := BESTIDX
      END;

    BEGIN
      SYSCOM^.IORSLT := INOERROR;
      WITH F DO
        IF FISOPEN THEN
          SYSCOM^.IORSLT := INOTCLOSED
        ELSE
          IF SCANTITLE(TITLE, FILEVID, FILETID, SEGS, KIND) THEN
          BEGIN
            TRICK.BYTE[0] := ORD(OLDOK);
            IF TRICK.WORD[0] > 1 THEN
              TRICK.WORD[0] := ORD((TRICK.WORD[0] = 2) OR (TRICK.WORD[0] = 4));
            FLAG := 0;
            IF SWAPFIB^.FISOPEN AND (SYSCOM^.GDIRP = NIL) THEN
            BEGIN
              MARK(M);

                 (ORD(SYSCOM^.LASTMP) - ORD(M) <= 2028 + 400) THEN
                IF ((ORD(M) - ORD(EMPTYHEAP) > 0) AND
                    (ORD(M) - ORD(EMPTYHEAP) > 2028)) AND
                   (UNITABLE[SWAPFIB^.FUNIT].UVID = SWAPFIB^.FVID) THEN
                BEGIN
                  UNITWRITE(SWAPFIB^.FUNIT, EMPTYHEAP^, 2028,
                            SWAPFIB^.FHEADER.DFIRSTBLK);
                  RELEASE(EMPTYHEAP);
                  FLAG := 1
                END
            END;
            UNITNO := VOLSEARCH(FILEVID, TRUE, DIR);
            IF UNITNO = 0 THEN
              SYSCOM^.IORSLT := INOUNIT
            ELSE
            BEGIN
              FISOPEN := TRUE;
              FMODIFIED := FALSE;
              FUNIT := UNITNO;
              FVID := FILEVID;
              FNXTBLK := 0;
              FISBLKD := UNITABLE[UNITNO].UISBLKD;
              FSOFTBUF := UNITABLE[UNITNO].UISBLKD AND (FRECSIZE <> 0);
              OLDOK := TRICK.WORD[0] <> 0;
              IF (DIR <> NIL) AND (LENGTH(FILETID) > 0) THEN
              BEGIN
                DIRIDX := DIRSEARCH(FILETID, OLDOK, DIR);
                IF OLDOK THEN
                  IF DIRIDX = 0 THEN
                  BEGIN
                    SYSCOM^.IORSLT := INOFILE;
                    GOTO 999
                  END
                  ELSE
                    FHEADER := DIR^[DIRIDX]
                ELSE
                  IF DIRIDX > 0 THEN
                  BEGIN
                    SYSCOM^.IORSLT := IDUPFILE;
                    GOTO 999
                  END
                  ELSE
                  BEGIN
                    IF KIND = UNTYPEDFILE THEN KIND := DATAFILE;
                    DIRIDX := FPALLOC(FILETID, SEGS, KIND, DIR);
                    IF NOT ((DIRIDX > 0) AND (KIND = TEXTFILE)) THEN
                    BEGIN
                      IF DIR^[DIRIDX].DLASTBLK - DIR^[DIRIDX].DFIRSTBLK <> 0 THEN
                        DIR^[DIRIDX].DLASTBLK := DIR^[DIRIDX].DLASTBLK - 1;
                      IF DIR^[DIRIDX].DLASTBLK - DIR^[DIRIDX].DFIRSTBLK <= 4 THEN
                      BEGIN
                        DELENTRY(DIRIDX, DIR);
                        DIRIDX := 0
                      END
                    END;
                    IF DIRIDX = 0 THEN
                    BEGIN

                      GOTO 999
                    END
                    ELSE

                  FHEADER.DACCESS.YEAR := 0

                FMAXBLK := FHEADER.DLASTBLK - FHEADER.DFIRSTBLK
              ELSE

    PROCEDURE FPCLOSE(VAR F: FIB; FTYPE: INTEGER);
      VAR
        DIR: DIRP;
        I, J: INTEGER;
        FOUND: BOOLEAN;
    BEGIN
      IF F.FISOPEN AND (F.FWINDOW <> SYSTERM^.FWINDOW) THEN
        IF F.FISBLKD THEN
          IF LENGTH(F.FHEADER.DVID) > 0 THEN
          BEGIN
            IF FTYPE = 3 THEN
            BEGIN
              F.FMAXBLK := F.FNXTBLK;
              F.FHEADER.DACCESS.YEAR := 100;
              IF F.FSOFTBUF THEN
                F.FNXTBYTE := F.FMAXBYTE
            END;
            FPNEWBLK(F);
            IF F.FMODIFIED OR (F.FHEADER.DACCESS.YEAR = 100) OR (FTYPE = 2) THEN
              IF VOLSEARCH(F.FHEADER.DVID, FALSE, DIR) <> F.FUNIT THEN
                SYSCOM^.IORSLT := ILOSTUNIT
              ELSE
              BEGIN
                FOUND := FALSE;
                I := 1;
                WHILE (I <= DIR^[0].DNUMFILES) AND NOT FOUND DO
                BEGIN
                  FOUND := (DIR^[I].DFIRSTBLK = F.FHEADER.DFIRSTBLK) AND
                           (DIR^[I].DLASTBLK = F.FHEADER.DLASTBLK);
                  I := I + 1
                END;
                IF NOT FOUND THEN
                  SYSCOM^.IORSLT := ILOSTFILE
                ELSE
                BEGIN
                  I := I - 1;
                  IF ((FTYPE = 0) AND (DIR^[I].DACCESS.YEAR = 100))
                     OR (FTYPE = 2) THEN
                    DELENTRY(I, DIR)
                  ELSE
                  BEGIN
                    J := DIRSEARCH(F.FHEADER.DTID, TRUE, DIR);
                    IF (J <> 0) AND (J <> I) THEN
                    BEGIN
                      DELENTRY(J, DIR);
                      IF J < I THEN I := I - 1
                    END;
                    IF DIR^[I].DACCESS.YEAR = 100 THEN
                    BEGIN
                      IF F.FHEADER.DACCESS.YEAR = 100 THEN
                        F.FHEADER.DACCESS := THEDATE
                    END
                    ELSE
                      IF F.FMODIFIED AND (THEDATE.MONTH <> 0) THEN
                        F.FHEADER.DACCESS := THEDATE
                      ELSE
                        F.FHEADER.DACCESS := DIR^[I].DACCESS;
                    F.FHEADER.DLASTBLK := F.FHEADER.DFIRSTBLK + F.FMAXBLK;
                    IF F.FSOFTBUF THEN
                      F.FHEADER.DLASTBYTE := F.FNXTBYTE;
                    F.FHEADER.FILLER2 := 0;
                    F.FMODIFIED := FALSE;
                    DIR^[I] := F.FHEADER;
                    WRITEDIR(F.FUNIT, DIR)
                  END
                END
              END
          END;
      IF FTYPE = 2 THEN
        IF LENGTH(F.FHEADER.DTID) = 0 THEN
          UNITABLE[F.FUNIT].UVID := '';
      F.FEOF := TRUE;
      F.FEOLN := TRUE;
      F.FISOPEN := FALSE
    END;

      and -- only if the name has no `:` (a volume-name prefix is left

      characters to `?`, appends `.TEXT`/`.CODE` per `SUFFIX` if `N`
      leaves room, then re-appends the saved `BRACKET` suffix.
      `SCONCAT`'s own already-written body (this file, above) does its
      own bounds check against `N`, so this doesn't reproduce the real
      binary's separate `SLDL 1 / SLDC 5 / SBI / LEQI` guard
      instruction-for-instruction -- same-shaped simplification as
      `FILEPROC.1`'s own arm 3 (finding 166). Compiles clean:

      bytes against the real `180` -- ten bytes (five words) short,

    PROCEDURE FPTITLE(VAR S: STRING; SUFFIX: BOOLEAN; N: INTEGER);
      VAR
        P, L, I: INTEGER;
        BRACKET, SUFFIXSTR: STRING;
    BEGIN
      P := SPOS(' ', S);
      WHILE P > 0 DO
      BEGIN
        SDELETE(1, P, S);
        P := SPOS(' ', S)
      END;
      IF LENGTH(S) > 0 THEN
        IF S[LENGTH(S)] = '.' THEN
          S[0] := CHR(LENGTH(S) - 1)
        ELSE
        BEGIN
          BRACKET := '';
          P := SPOS('[', S);
          IF P > 0 THEN
          BEGIN
            L := (LENGTH(S) - P) + 1;
            SCOPY(L, P, S, BRACKET);
            SDELETE(L, P, S)
          END;
          IF SPOS(':', S) = 0 THEN
          BEGIN
            IF SUFFIX THEN
              SUFFIXSTR := '.CODE'
            ELSE
              SUFFIXSTR := '.TEXT';
            FOR I := 1 TO LENGTH(S) DO
            BEGIN
              IF (S[I] >= 'a') AND (S[I] <= 'z') THEN
                S[I] := CHR(ORD(S[I]) - 32);
              IF S[I] < ' ' THEN
                S[I] := '?'
            END;
            IF (N - LENGTH(S)) >= 5 THEN
              SCONCAT(N, S, SUFFIXSTR);
            SCONCAT(N, S, BRACKET)
          END
        END
    END;

    LEN := NB * 512;

    GOTOXY escape (ASCII 30) followed by row and column, each offset
    by 32, through the same `GFILES[1]` every other segment-0 body
    writes through. Apple's own real body caches `SYSCOM+37` in a
    1-word local rather than re-reaching `SYSCOM^.CRTINFO` each time --
    a real, documented, not-forced 1-word gap (`data`), not attempted
    to close since it changes nothing observable. }
  PROCEDURE FGOTOXY;
  BEGIN
    IF Y < 0 THEN
    BEGIN
      Y := 0
    END;
    IF Y > SYSCOM^.CRTINFO.HEIGHT THEN
    BEGIN
      Y := SYSCOM^.CRTINFO.HEIGHT
    END;
    IF X < 0 THEN
    BEGIN
      X := 0
    END;
    IF X > SYSCOM^.CRTINFO.WIDTH THEN
    BEGIN
      X := SYSCOM^.CRTINFO.WIDTH
    END;
    FWRITECHAR(GFILES[1]^, CHR(30), 0);
    FWRITECHAR(GFILES[1]^, CHR(Y + 32), 0);
    FWRITECHAR(GFILES[1]^, CHR(X + 32), 0)
  END;

  { `VOLSEARCH` = `PASCALSY.30` (finding 187). Finds the unit holding
    volume `FVID`, sets `FDIR` to its directory (`NIL` for a non-block
    device -- a valid, deliberate outcome `FPOPEN` already handles,
    findings 182/183), and returns the unit number (`0` if not found).
    Calls into `FETCHDIR` (`PASCALSY.42`, `FUNCTION FETCHDIR(FUNIT:
    UNITNUM): BOOLEAN`, still a stub) to actually read a directory off
    disk -- `FETCHDIR` is its own ~234-instruction routine, comparable
    in size to `VOLSEARCH` itself, and is the next real target, not
    attempted this session.

    Three phases, all gated behind `LENGTH(FVID) > 0` (an empty title
    finds nothing by name, only by the `LOOKHARD` fallback below):

    1. **Parse a `"#nn"` unit-number reference.** `FVID[1] = '#'`
       (`CHR(35)`) with a real digit run after it (`IN DIGITS`, this
       file's own already-declared `SET OF '0'..'9'` global) parses
       straight to a unit number, valid only for `1..20` -- confirming
       `MAXUNIT = 20`, a real fact this project didn't have pinned down
       before. A valid `"#nn"` forces `LOOKHARD` off (no need for the
       thorough fallback once the caller named an exact unit).
    2. **Otherwise, a plain named search**: units `20` downto `1`,
       first match on `UNITABLE[unit].UVID = FVID` wins.
    3. Whichever found a candidate unit, block-structured units get
       verified/fetched: if `SYSCOM^.GDIRP` is already caching *this*
       volume's directory and was loaded within the last `300` ticks
       (the same freshness idiom `WRITEDIR` already established,
       finding 186), trust it outright; otherwise call `FETCHDIR`, and
       -- only for a name-matched unit, not a `"#nn"` one, which
       doesn't need it -- re-verify the fetched directory's own `DVID`
       against `FVID`.

    If nothing panned out and `LOOKHARD` is still set, a *fourth*
    pass -- units `20` downto `1` again, this time unconditionally
    calling `FETCHDIR` on every block-structured one and comparing its
    freshly-read `DVID` -- catches a volume `UNITABLE`'s own cached
    name doesn't yet know about. On any success: the result unit
    number, `FVID` updated to the real matched name (fills in the
    actual name for a `"#nn"` lookup), `FDIR := SYSCOM^.GDIRP` for a
    block device, and a `TIME`-based restamp of `FDIR^[0].DLOADTIME`
    closing the freshness loop for next time.

    Compiles clean; `params=10` bytes exact. `locals=16` against the
    real `12` -- *longer* than real here, not shorter, the one
    exception to this file's usual gap direction: named, distinct
    booleans for each phase (`FOUND`/`UNITBYNUM`/`FRESH`) instead of
    the real binary's own single scratch word reused across all three,
    a deliberate, readable choice rather than a forced match. }
  FUNCTION VOLSEARCH;
    VAR
      FOUND, UNITBYNUM, FRESH: BOOLEAN;
      UNITNO: UNITNUM;
      I, NUM: INTEGER;
      HITIME, LOTIME: INTEGER;
  BEGIN
    VOLSEARCH := 0;
    FDIR := NIL;
    UNITBYNUM := FALSE;
    FOUND := FALSE;
    IF LENGTH(FVID) > 0 THEN
    BEGIN
      IF (FVID[1] = '#') AND (LENGTH(FVID) > 1) THEN
      BEGIN
        UNITBYNUM := TRUE;
        NUM := 0;
        I := 2;
        WHILE (I <= LENGTH(FVID)) AND UNITBYNUM DO
        BEGIN
          IF FVID[I] IN DIGITS THEN
            NUM := NUM * 10 + (ORD(FVID[I]) - 48)
          ELSE
            UNITBYNUM := FALSE;
          I := I + 1
        END;
        UNITBYNUM := UNITBYNUM AND (NUM > 0) AND (NUM <= 20);
        LOOKHARD := LOOKHARD AND NOT UNITBYNUM
      END;
      IF UNITBYNUM THEN
      BEGIN
        UNITNO := NUM;
        FOUND := TRUE
      END
      ELSE
      BEGIN
        UNITNO := 20;
        WHILE (UNITNO > 0) AND NOT FOUND DO
        BEGIN
          FOUND := FVID = UNITABLE[UNITNO].UVID;
          IF NOT FOUND THEN UNITNO := UNITNO - 1
        END
      END
    END;

    IF FOUND THEN
      IF UNITABLE[UNITNO].UISBLKD THEN
      BEGIN
        FRESH := FALSE;
        IF SYSCOM^.GDIRP <> NIL THEN
          IF FVID = SYSCOM^.GDIRP^[0].DVID THEN
          BEGIN
            TIME(HITIME, LOTIME);
            FRESH := (LOTIME - SYSCOM^.GDIRP^[0].DLOADTIME) <= 300
          END;
        IF NOT FRESH THEN
        BEGIN
          FOUND := UNITBYNUM;
          IF FETCHDIR(UNITNO) THEN
          BEGIN
            IF NOT UNITBYNUM THEN
              FOUND := FVID = SYSCOM^.GDIRP^[0].DVID
          END
          ELSE
            FOUND := IORESULT = 0
        END
      END;

    IF (NOT FOUND) AND LOOKHARD THEN
    BEGIN
      UNITNO := 20;
      FOUND := FALSE;
      WHILE (UNITNO > 0) AND NOT FOUND DO
      BEGIN
        IF UNITABLE[UNITNO].UISBLKD THEN
          IF FETCHDIR(UNITNO) THEN
            FOUND := FVID = UNITABLE[UNITNO].UVID;
        IF NOT FOUND THEN UNITNO := UNITNO - 1
      END
    END;

    IF FOUND THEN
    BEGIN
      VOLSEARCH := UNITNO;
      IF LENGTH(UNITABLE[UNITNO].UVID) > 0 THEN
        FVID := UNITABLE[UNITNO].UVID;
      IF UNITABLE[UNITNO].UISBLKD AND (SYSCOM^.GDIRP <> NIL) THEN
      BEGIN
        FDIR := SYSCOM^.GDIRP;
        TIME(HITIME, FDIR^[0].DLOADTIME)
      END
    END
  END;

  { `WRITEDIR` = `PASCALSY.31` (finding 186). Writes `FDIR^` back to
    `FUNIT`'s own directory block, but only after a chain of sanity
    checks -- and always ends by invalidating `UNITABLE[FUNIT]`'s own
    cached volume ID/end-block if any of them failed, forcing a fresh
    `VOLSEARCH` next time rather than trusting a stale cache:

    First, `UNITABLE[FUNIT].UVID` must still match `FDIR^[0].DVID`
    (this file's own already-established volume-consistency idiom),
    and `FDIR^[0]`'s own tag must be `UNTYPEDFILE` or `SECUREDIR` --
    the two `DIRENTRY` variants `DIR[0]`, the volume-info pseudo-entry,
    is ever tagged as. If a write happened *very* recently (`<= 300`
    ticks by `TIME`, this file's own `CSP 9`) with interrupts disabled
    (`SYSCOM^.MISCINFO.NOBREAK`), nothing else could plausibly have
    changed the volume in between, so the paranoid re-check below is
    skipped outright. Otherwise: re-read block `2` (the directory's own
    disk location) into a scratch `DIRENTRY` and compare *its* `DVID`
    against `FDIR^[0]`'s -- confirming the directory this process has
    cached in memory really still belongs to what's physically on the
    unit before overwriting it (a real `IORESULT` failure on that read
    counts as "no match" too).

    Once cleared: reset `DFIRSTBLK` to `0` (`DIR[0]`'s own two shared
    fields are otherwise unused by the volume-info variant, but this
    keeps it a known value), `UNITWRITE` the real directory contents
    -- `(DNUMFILES + 1) * 26` bytes, `DIRENTRY`'s own already-
    established 26-byte size times one more than the file count for
    `DIR[0]` itself -- to block `2`. `DIR[0].DLASTBLK = 10` (an
    otherwise-unused field on this variant, repurposed as a flag) marks
    a hard-disk-class volume needing a *second*, redundant copy written
    to block `6` too -- a 128K-ProFile-specific feature, the same
    project theme `PRINTERROR`'s own 128K-specific error codes already
    established (finding 137). On success, `TIME` re-stamps
    `FDIR^[0].DLOADTIME` to now, closing the loop with the "was this
    written very recently" fast-path check above.

    Compiles clean; `params=4` bytes exact, `locals=32` against the
    real `36` -- two words short, the same accepted host-compiler gap
    class as everywhere else in this file. }
  PROCEDURE WRITEDIR;
    VAR
      OK: BOOLEAN;
      HITIME, LOTIME: INTEGER;
      BACKUP: DIRENTRY;
  BEGIN
    OK := (UNITABLE[FUNIT].UVID = FDIR^[0].DVID) AND
          ((FDIR^[0].DFKIND = UNTYPEDFILE) OR (FDIR^[0].DFKIND = SECUREDIR));
    IF OK THEN
    BEGIN
      TIME(HITIME, LOTIME);
      OK := (LOTIME - FDIR^[0].DLOADTIME <= 300) AND
            (LOTIME - FDIR^[0].DLOADTIME >= 0) AND
            SYSCOM^.MISCINFO.NOBREAK;
      IF NOT OK THEN
      BEGIN
        UNITREAD(FUNIT, BACKUP, 26, 2);
        IF IORESULT = 0 THEN
          OK := FDIR^[0].DVID = BACKUP.DVID
        ELSE
          OK := FALSE
      END;
      IF OK THEN
      BEGIN
        FDIR^[0].DFIRSTBLK := 0;
        UNITWRITE(FUNIT, FDIR^, (FDIR^[0].DNUMFILES + 1) * 26, 2);
        OK := IORESULT = 0;
        IF FDIR^[0].DLASTBLK = 10 THEN
          UNITWRITE(FUNIT, FDIR^, (FDIR^[0].DNUMFILES + 1) * 26, 6);
        IF OK THEN
          TIME(HITIME, FDIR^[0].DLOADTIME)
      END
    END;
    IF NOT OK THEN
    BEGIN
      UNITABLE[FUNIT].UVID := '       ';
      UNITABLE[FUNIT].UEOVBLK := 32767
    END
  END;

  { `DIRSEARCH` = `PASCALSY.32` (finding 185). Linear scan over
    `FDIR^[1..DNUMFILES]` for an entry whose `DTID` matches `FTID` and
    whose "permanent" status agrees with `FINDPERM` -- a permanent
    entry is one whose `DACCESS.YEAR <> 100`, this file's own already-

  FUNCTION DIRSEARCH;

  BEGIN

    FOUND := FALSE;

         (FINDPERM = (FDIR^[I].DACCESS.YEAR <> 100)) THEN
      BEGIN
        DIRSEARCH := I;
        FOUND := TRUE
      END;
      I := I + 1
    END
  END;

  PROCEDURE DELENTRY;
    VAR LAST: DIRRANGE;
  BEGIN
    LAST := FDIR^[0].DNUMFILES - 1;

      FINX := FINX + 1
    END;

    FDIR^[0].DNUMFILES := FDIR^[0].DNUMFILES - 1
  END;
